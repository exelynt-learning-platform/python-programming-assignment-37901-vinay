# Git Installation and Configuration

## 1. Git Installation

**Operating System:** macOS

Git was installed using Homebrew.

Command:
```bash
brew install git
```

## 2. Git Version Verification

Git installation was verified using:

```bash
git --version
```

The command successfully displayed the installed Git version.

**Evidence:** Screenshot 1.

## 3. Global Username and Email Configuration

Git global identity was configured using:

```bash
git config --global user.name "Your Full Name"
git config --global user.email "your-email@example.com"
```

The configuration was verified using:

```bash
git config --global --list
```

**Evidence:** Screenshot 2.

## 4. Git Terminal Demonstration

The following Git operations were successfully demonstrated:

- Created a practice directory.
- Initialized a Git repository using `git init`.
- Created a README.md file.
- Checked repository status using `git status`.
- Staged changes using `git add`.
- Created a commit using `git commit`.
- Viewed commit history using `git log --oneline`.

**Evidence:** Screenshots 3 and 4.

## 5. Conclusion

Git was successfully installed and configured on macOS. Its version was verified, global username and email were configured, and basic Git repository operations were demonstrated using Terminal.
